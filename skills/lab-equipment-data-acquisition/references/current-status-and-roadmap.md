## 常见风险

- `IB_TBS_DETAILEDINF` 是全业务附件表，漏掉 `INSTFILE` 关系会混入无关文件。
- `FINSTNO` 是接口编号，不一定唯一标识物理设备。
- 上传成功与解析成功不同，状态不能仅取客户端 HTTP 结果。
- `RSLT1...RSLT6` 是通用槽位，必须按仪器解释。
- 本地调试会话可能注入 `empid=999、hiino=0`；这不代表平台注册用户值。
- Oracle 字符业务编号写入 NUMBER 会触发 `ORA-01722`。
- 源码文件存在不代表 Java 已打包或服务器接口已上线。
- 本地三级目录不能原样同步到部署目录，否则模板/静态资源路径异常。
